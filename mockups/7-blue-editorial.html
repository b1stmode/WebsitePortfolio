STANDBY: Your Range Tool

Shot timer and training companion for airsoft and range training.

View live ↗

A mobile-first Progressive Web App built for use on the range, during the drill, in the moment — timer, drill library, and training log in a single offline-capable tool. Designed and directed by me, with implementation developed through an AI-assisted workflow.

Claude Code · JavaScript · HTML · CSS · IndexedDB · Cloudflare

Key features
  • Offline-first PWA — installable on phone and desktop, no account required
  • Audio-based shot detection — mic stops the timer on confirmed shots
  • Drill library with built-in classics and a custom drill builder
  • Calibration system — measures ambient noise to suggest your threshold
  • Training log — notebook-style entries with splits and scores
  • Field Mode for outdoor readability in direct sunlight
